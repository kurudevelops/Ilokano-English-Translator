# ================= meaning of tags ========================= #
# PN = Proper Noun (names)
# N = Noun (common)
# NP = Noun Phrase
# V = Verb (base form)
# VP = Verb Phrase
# Adj = Adjective
# Adv = Adverb
# Det = Determiner (ti, ni, daytoy, etc.)
# Prep = Preposition
# Conj = Conjunction
# Aux = Modal Auxiliary (mabalin, kayat, etc.)
# Neg = Negation (haan, saan, etc.)
# Wh_Q = Wh-Question word (apay, kasano, etc.)
# PP = Prepositional Phrase
# S = Sentence
# Pronoun = Personal or reflexive pronoun
# Adda = Existential predicate (there is / adda)
